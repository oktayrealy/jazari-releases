# Jazari — İndirmeler

Bu depo yalnızca **dağıtım paketlerini** barındırır. Kaynak kod burada
değildir.

En son sürüm: **[Releases](../../releases/latest)**

| Platform | Paket |
|---|---|
| macOS (Apple Silicon) | `.dmg` — `aarch64` |
| macOS (Intel) | `.dmg` — `x64` |
| Windows 10+ | `.exe` (kurulum sihirbazı) |
| Debian / Ubuntu | `.deb` |
| Diğer Linux | `.AppImage` |

Paketleri indirmenin kolay yolu: **[jazari.app/indir](https://jazari.app)**

## Neden ayrı bir depo?

Kaynak deposu özeldir ve özel depoların sürüm dosyaları kimlik doğrulaması
olmadan indirilemez — siteye konulan doğrudan bağlantı herkese 404 dönerdi.
Paketler burada, kaynak kod orada kalıyor.

## Sorun bildirimi

Uygulamanın içinden **Ayarlar → Destek**, ya da destek@jazari.app.
